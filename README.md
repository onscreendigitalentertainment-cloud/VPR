# VPR
The first Vroid Material Converter for realistic results.

<img width="3264" height="1836" alt="20260928_133842" src="https://github.com/user-attachments/assets/89e8be42-0700-4895-ac36-a54862509315" />

VPR is a blender addon that converts your MToon materials from your VRM models into blender standard materials. This addon is especially for those who wants/needs an anime + realistic look in their games or animations.


The addon was made with Godot and UnrealEngine in mind, as other addons which tries to convert materials requires changing the core structure of the model (VRM -> MMD) which removes the inbuilt physics simulation when importing to game engines and can become annoying very fast.


This addon only touches your materials, leaving the skeleton and physics bones as is.


Installation:


Blender -> Edit -> Preferences -> Extensions -> Install from disk (Top-Right Drop Down Arrow) -> select the VPR zip file. 

- The addon will be enabled automatically


Use:

Press N -> Scroll down to VRM -> PBR -> select -> tweak parameters for skin, hair, eyes, etc -> press the convert material button -> tweak shadow/light values if necessary
